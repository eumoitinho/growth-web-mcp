# Support / Suporte / Soporte

## English

Use [GitHub Issues](https://github.com/eumoitinho/growth-web-mcp/issues/new/choose) for bugs, feature requests and usage questions. Search existing issues first. Include the affected integration, commit/version, deployment method, expected behavior and sanitized error output. Support is community-based; there is no guaranteed response time or managed hosting service.

Never post credentials, customer records or private account exports. For vulnerabilities, follow [SECURITY.md](SECURITY.md). English, Portuguese and Spanish are welcome.

## Português

Use [GitHub Issues](https://github.com/eumoitinho/growth-web-mcp/issues/new/choose) para bugs, sugestões e dúvidas. Pesquise as issues existentes antes. Informe integração, commit/versão, forma de implantação, comportamento esperado e erros sem dados sensíveis. O suporte é comunitário, sem prazo garantido ou serviço de hospedagem gerenciada.

Não publique credenciais, registros de clientes ou exports privados. Para vulnerabilidades, siga [SECURITY.md](SECURITY.md). Aceitamos português, inglês e espanhol.

Incluye integración, commit/versión, método de despliegue, comportamiento esperado y errores sin datos sensibles. El soporte es comunitario, sin plazo garantizado ni alojamiento gestionado.
