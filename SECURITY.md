# Security / Segurança / Seguridad

## English

Report vulnerabilities privately to **joao@relator.digital**, including the affected commit, impact and a minimal reproduction with fictional data. Do not open a public issue or include live credentials. Security fixes target the latest code on `main`; older snapshots have no separate maintenance commitment. No response-time SLA is offered.

## Português

Relate vulnerabilidades em privado para **joao@relator.digital**, com commit afetado, impacto e reprodução mínima usando dados fictícios. Não abra issue pública nem inclua credenciais reais. As correções são destinadas ao código atual da `main`; versões antigas não têm compromisso separado de manutenção. Não há SLA de resposta.

## Español

Reporta vulnerabilidades en privado a **joao@relator.digital**, incluyendo commit afectado, impacto y reproducción mínima con datos ficticios. No abras una issue pública ni incluyas credenciales reales. Las correcciones se dirigen al código actual de `main`; las versiones anteriores no tienen un compromiso separado de mantenimiento. No se ofrece SLA de respuesta.
